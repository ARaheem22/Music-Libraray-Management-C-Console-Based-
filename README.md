# Music Library Management System

A program written in c++ to manage music collections

### Features
- Authentication
- Searching
- Sorting
- Multiple Playlists
- Collection of 500 songs
- Music recommendations based on user's mood
- SFML for playing songs while the program is running

## Setup

### For Dev-Cpp
1. Download the source code
2. Create a new folder
3. Create a new **empty** project in devcpp
4. Add the source code files in the devcpp project
5. Open project settings and go to **compiler options**
6. Under compiler options go to **Code generation** and in the __Language Standard (-std)__ select **ISO C++11**
7. After you are done with the above steps, follow this [tutorial](https://youtu.be/uAd2jINKCxc?si=rNuAy2hZeIRT3Nud) for SFML setup
